# GlandersWatch

Predicts, for a country and year, whether glanders will be reported there the following year.

B.Tech project, IIIT Bhubaneswar. Authors: Pedapatruni Shanmuk Vardhan (B123089), Shaktimayee Mohanty (B123118), Yuvraj Singh (B123153). Supervisor: Dr. Sangita Dhara.

Code only. Reports, figures and data are generated by the pipeline, not versioned.

## How it works

One binary classifier over 8 features. Trained on 2,880 country-years (160 countries, 2006–2023, 169 positives). Validated by training on 2006–2017 and testing on 2018–2023.

| | |
|---|---|
| Champion | logistic regression, leave-country-out PR-AUC 0.381 |
| Best temporal | random forest, PR-AUC 0.495 |
| Features | `pop_total`, `years_since_last`, `temp_mean_anom`, `internet_pct`, `humidity_anom`, `precip_cv`, `log_livestock`, `goats` |

PR-AUC is the primary metric: at 5.87% prevalence, ROC-AUC sits at 0.80–0.87 for every model and cannot separate them.

Two further components (RAG explanation, alert service) are specified in the report but not implemented here.

## Run it

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python src/01_fetch_data.py
python src/01c_extract_faostat.py
python src/02_build_panel.py
python src/shap_select.py
python src/03_train_evaluate.py
```

## Two rules that matter

`03_train_evaluate.py::load_level1` owns the row filters; `05_dataset_analysis.py` imports it. Do not add a private copy — that is how the analysis and models drifted apart before.

After changing the feature selection, re-run `11_export_model_matrix.py`, or the matrix will describe a different model from the one that ran.

Country codes and calendar years are identifiers, not predictors. A country code cannot transfer to an unseen country, and the year tracks reporting growth rather than disease.

## Collaborating

`main` is the integration branch. Work on your own branch; only the owner merges.

```bash
git clone https://github.com/YuvrajSingh-mist/glandersWatch-demo.git
cd glandersWatch-demo
git switch -c <your-name>/<what-you-are-changing> origin/main
# edit, commit, push your branch
```

1. Never commit on `main`.
2. Never merge, into anything.
3. Never force-push.
4. Do not commit generated output (`data/`, `reports/`, `figures/`, PDFs).
